- Пусть для вероятностей в конечном пространстве элементарных исходов $\Omega = \{\omega_1, \omega_2, \omega_3, \omega_4\}$ выполнены равенства $4p_1=3p_2=2p_3=p_4$. Найдите $p_1$. 
  
**Решение и ответ:** $p_1 \left(1+\cfrac{4}{3}+\cfrac{4}{2}+4\right) =p_1 \cfrac{25}{3} = 1 \;\Rightarrow \;  p_1 = \cfrac{3}{25}$ 
   
- Подбрасывается неидеальный шестигранный игральный кубик, на котором вероятность выпадения $k$ очков пропорциональна $k$. С какой вероятностью на нём выпадет нечётное число очков?
	  **Решение и ответ:** $p+2p+3p+4p+5p+6p = 21p = 1 \;\Rightarrow p = \cfrac{1}{21} \; \Rightarrow P(k = 1 \vee k = 3 \vee k = 5) = \cfrac{9}{21} = \cfrac{3}{7}$.   

- Рассмотрим эксперимент с одновременным подбрасыванием двух шестигранных игральных кубиков — красного и белого. Элементарным исходом будем считать пару чисел, первое из которых равно числу очков, выпавших на красном кубике, а второе — числу очков, выпавших на белом. Зададим случайную величину $X$, равную произведению чисел, выпавших на этих кубиках. Перечислите все элементарные исходы, которые будут принадлежать событию $X=12$.

	 **Решение и ответ:** $(2,6), \, (6,2), \, (3,4), \, (4,3)$. 

- Рассмотрим эксперимент с одновременным подбрасыванием трёх шестигранных игральных кубиков — красного, белого и синего. Элементарным исходом будем считать тройку чисел, первое из которых равно числу очков, выпавших на красном кубике, второе — числу очков, выпавших на белом кубике, третье — числу очков, выпавших на синем. Зададим случайную величину $X$, равную сумме чисел, выпавших на этих кубиках. Сколько элементарных исходов будут принадлежать событию $X=17$?
  
	**Решение и ответ:** $3$

- Случайная величина $X$ имеет распределение $Binom(4,1/3)$. Найдите $P(X=1)$.
	  $P(X = 1) = C_4^1 (1/3)^1 (2/3)^3 = 32/81$.
- Говорят, что случайная величина имеет **_дискретное равномерное распределение_**, если она принимает каждое своё значение с одинаковой вероятностью.
  Рассмотрим эксперимент: выбирается натуральное число от $1$ до $10$, все исходы равновероятны. Выберите все равномерно распределённые случайные величины:
	  - $X(n) = n$ (да)
	  - $X(n) = n (\mod 2)$ (да)
	  - $X(n) = n (\mod 3)$
	  - $X(n) = n (\mod 5)$ (да)

- В урне $8$ шаров, из которых $5$ белых, остальные черные. Из нее наудачу вынимают $3$ шара. Найти закон распределения числа белых шаров в выборке.
	- $P(X = 0) = \cfrac{C_5^0\cdot C_3^3}{C_8^3} = \cfrac{1}{56}$;
	- $P(X = 1) = \cfrac{C_5^1\cdot C_3^2}{C_8^3} = \cfrac{15}{56}$;
	- $P(X = 2) = \cfrac{C_5^2\cdot C_3^1}{C_8^3} = \cfrac{30}{56} = \cfrac{15}{28}$;
	- $P(X = 3) = \cfrac{C_5^3\cdot C_3^0}{C_8^3} = \cfrac{10}{56} = \cfrac{5}{28}$.
