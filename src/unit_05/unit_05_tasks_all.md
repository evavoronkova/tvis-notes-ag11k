## Задача 1.

 Сколько различных случайных величин можно задать на пространстве из $n$ элементарных исходов, принимающих значения в множестве из $m$ элементов (не обязательно все)?

### Решение

- $\Omega = \{\omega_1, \ldots, \omega_n\}$; 
- $X: \Omega \to \{a_1, \ldots, a_m\}$;
- $m$ вариантов значений для $\omega_1$, $m$ вариантов значений для $\omega_2$  и т.д.
- Всего $m^n$ случайных величин.

## Задача 2.


_Усечённое геометрическое распределение._ Рассмотрим схему испытаний Бернулли с параметрами $n$ и $p$. Определим случайную величину $X$ следующим образом: $X(\omega)$  равно номеру первого успеха в элементарном исходе $\omega$; если $\omega$ - это элементарный исход, состоящий из всех неудач, то $X(\omega)$ равно $n$. Найдите распределение $X$.


### Решение

- $X$ - номер первого успеха в схеме Бернулли с параметрами $n$ и $p$; Если сплошь неудачи, то $X = n$;
- $P(X = k)$ - ?
	- $k<n$:
	  $P(X=k) = (1-p)^{k-1}\cdot p$ 
	- $k = n$
	  $P(X = n) = (1-p)^{n-1}\cdot p + (1-p)^n = (1-p)^{n-1}$
- $\sum\limits_{k = 1}^n P(X = k) = p + p\cdot (1-p) + p\cdot (1-p)^2+ \ldots + p\cdot (1-p)^{n-1} + (1-p)^{n - 1} =$
  $= \cfrac{p\cdot ((1-p)^{n-1} - 1)}{(1-p) - 1)} + (1-p)^{n-1} = 1$.
